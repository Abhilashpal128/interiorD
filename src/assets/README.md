# S&D Build Solutions client media

21 photographs and 5 videos supplied for this website. All originals are retained without recompression or visual alteration. See `asset-manifest.json` for original WhatsApp filenames, descriptive replacements and SHA-256 checksums.

`../data/media.ts` imports every supplied file and defines captions. Photos are grouped by visible subject in `projects.ts`; collections do not imply a verified number of separate commissions. Site locations, exact materials, prices, areas and completion dates were not supplied and are not inferred from the media.

The portrait sunset export and similar bathroom views are intentionally retained in their galleries. Photos with construction materials or incomplete finishes are described as installation or work in progress. Video durations were read from their MP4 metadata. Five still frames captured from the original videos are stored in `public/images/video-posters/` as lightweight playback posters.
